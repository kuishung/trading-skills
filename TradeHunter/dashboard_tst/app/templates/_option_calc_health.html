How to start it. On Hermes, in PowerShell from C:\trading-skills\TradeHunter\dashboard_tst: powershell -ExecutionPolicy Bypass -File deploy\setup_option_calc_task.ps1 -StartNow That installs (or re-installs) the {{ oc.task }} scheduled task and starts it. Its log is logs\option_calc_worker.log.
{% endif %}

How it updates - nothing to do by hand. The screener collector reads the whole option market from Massive about every 30 minutes. Once a minute this lane looks for a newer finished pass and recomputes every member's saved setups on the Option Calculator page against it, so the figures there always say which pass they come from. A setup it cannot compute (a leg no longer listed, no implied volatility) keeps the reason on the member's page and is tried again on the next pass.
