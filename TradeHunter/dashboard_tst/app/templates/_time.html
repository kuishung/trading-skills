{# Local-time helper. Server stamps are UTC; we emit an ISO-UTC element that the base.html `localtime` script rewrites to the VIEWER's local timezone (and re-runs after HTMX swaps). With JS off, the UTC text is the fallback. The trailing 'Z' is appended explicitly so the browser parses the value as UTC even when SQLite hands the datetime back naive (no tzinfo) — without it, `new Date("2026-06-17T13:13:00")` would be read as LOCAL and double-shift. Usage: {% from "_time.html" import localtime %} {{ localtime(some_dt) }} {{ localtime(some_dt, date_only=True) }} -> date with no clock {{ localtime(some_dt, time_only=True) }} -> clock with no date #} {% macro localtime(dt, date_only=False, time_only=False) -%} {%- if dt -%} {% if date_only %}{{ dt.strftime('%Y-%m-%d') }}{% elif time_only %}{{ dt.strftime('%H:%M') }} UTC{% else %}{{ dt.strftime('%Y-%m-%d %H:%M') }} UTC{% endif %} {%- else -%}-{%- endif -%} {%- endmacro %}
